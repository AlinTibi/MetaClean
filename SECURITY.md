# Security policy

Report suspected vulnerabilities in MetaClean privately to
[security@almarfeld.com](mailto:security@almarfeld.com).
Include the version, affected platform, impact, and reproducible steps when possible.
Do not include passwords, API keys, or private documents. Ask for a suitable way
to share sensitive evidence before sending it.

Security fixes are considered for the latest released version. Older versions may
require an upgrade. ALMARFELD is independently maintained; no response-time or
resolution guarantee is offered. Please allow time to investigate before public
disclosure. Ordinary bugs belong in the repository issue tracker.
